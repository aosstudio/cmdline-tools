# AOSStudio Command-Line Tools

AOSStudio Command-Line Tools provides SDK and virtual-device management, static analysis, APK inspection, app profile generation, resource shrinking, screenshot capture, and DEX tooling. The first release targets Linux x86-64 and installs as the SDK's `cmdline-tools;24.0` package.

The terms in [LICENSE](LICENSE) cover the project's build scripts, workflows, documentation, and verification fixtures. Upstream tools and dependencies retain their respective licenses and notices.
